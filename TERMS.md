# Terms

Codex Mobile Mail Bridge is provided as-is for local, user-controlled Codex workflows. It is not an official OpenAI email interface and does not provide a hosted service.

Use it only with email accounts and projects you control or are authorized to operate. Keep the default read-only sandbox unless you intentionally want email-triggered Codex commands to modify files.

The user is responsible for Gmail configuration, app-password handling, sender allowlists, project confidentiality, and any actions triggered by remote email commands.
